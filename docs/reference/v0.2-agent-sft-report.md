# v0.2 Agent SFT reference report

## Decision

The v0.2 Agent SFT reference gate passed on candidate commit `37acbc8`. The run used a clean locked
environment on the validated NVIDIA RTX 4070 Ti SUPER host and Docker for behavioral evaluation.

## Data contract

The gate collected five reviewed demonstrations and five real invalid-action recovery trajectories.
All 10 source episodes replayed semantically in fresh resets before tokenization. The frozen dataset
contained 24 training examples and six validation examples from a held-out task. Its longest
sequence was 2,646 tokens under the explicit 4,096-token limit.

Every example stores its messages, context policy, completion, typed target action, exact token IDs,
attention mask, current-action mask, prompt length, chat-template hash, task identity, trajectory
identity, step index, and source-file hash. The trainer checked the tokenizer and template hashes,
then consumed those stored IDs directly.

The full-transcript adapter executed `list_files → read_file → apply_patch → run_tests → finish`
with no policy violation. Generation used a protocol-aware stop: it stops only when the decoded
prefix is exactly one complete JSON object. The strict typed parser still rejects malformed output
and does not repair responses.

## Interpretation

This gate establishes exact multi-turn serialization, replay-linked tool and recovery data,
completion-only Agent SFT, strict behavioral evaluation, and a context-policy ablation. It does not
establish broad coding ability: the held-out set is one tiny task from a five-task educational
suite. The result is a vertical-slice validation, not a benchmark claim.
