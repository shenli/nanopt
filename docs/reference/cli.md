# CLI reference

Milestone 1 exposes only commands backed by implemented, tested behavior:

```text
nanopt --help
nanopt --version
nanopt version
nanopt doctor
nanopt config resolve
nanopt artifacts inspect RUN_DIR
```

Future data, evaluation, training, pipeline, agent, calibration, and reporting commands are added
with their vertical slices. The CLI does not advertise placeholders that silently do nothing.
