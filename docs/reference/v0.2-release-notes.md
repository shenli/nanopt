# NanoPT v0.2.0 release notes

NanoPT v0.2 turns the v0.1 MiniSWE evaluator into a small, complete Agent SFT laboratory.

## Added

- exact multi-turn message rendering shared by online inference and offline data generation;
- versioned Agent SFT example and dataset-manifest schemas;
- stored token IDs, attention masks, current-action masks, prompt lengths, and template hashes;
- replay-checked `list → read → patch → test → finish` demonstrations;
- invalid-action recovery demonstrations without training on the invalid action;
- task-level train/validation separation and trajectory-hash lineage;
- readable LoRA Agent SFT training with optimizer-boundary checkpoints;
- deterministic, JSON-protocol-aware agent decoding;
- explicit full-transcript versus observation-snapshot evaluation;
- a new Agent SFT chapter, lab, ADR, CLI reference, and retained GPU/Docker evidence.

## Measured reference result

On the validated RTX 4070 Ti SUPER, held-out action-token accuracy improved from 76.5% to 95.0%.
The adapted full-transcript policy produced 100% valid actions and solved both the demonstrated and
single held-out reference tasks. Peak reserved VRAM was 13.94 GiB.

## Scope

The task suite is intentionally tiny. v0.2 validates the educational Agent SFT pipeline and its
artifact contract; it does not claim general coding-agent performance. Agent RL remains planned for
v0.3.
