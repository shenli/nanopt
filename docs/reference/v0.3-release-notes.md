# NanoPT v0.3.0 release notes

NanoPT v0.3.0 adds a complete Mini Agent RL vertical slice on top of v0.2 Agent SFT.

## Added

- grouped MiniSWE rollouts from independent copies of one immutable task snapshot;
- exact per-turn prompt IDs, sampled IDs, masks, behavior log probabilities, and reference scores;
- hidden terminal outcome rewards and group-relative advantages;
- white-box clipped Agent GRPO updates with explicit KL and loss normalization;
- hard rejection of stale rollout groups at the trainer boundary;
- retained fresh-versus-stale policy-drift and approximate-ESS evidence;
- all-action versus terminal-action-only credit-coverage study;
- parent/final tool-budget comparison with continuous hidden verifier reward;
- validation-boundary policy selection that cannot fall back to the untrained parent;
- `nanopt train agent-rl`, strict profiles, schemas, reports, ADR, CPU lab, and course chapter.

## Reference result

The clean RTX 4070 Ti SUPER gate collected 4 groups, 16 episodes, and 80 action turns; all groups
were non-degenerate. Sampled action validity was 91.25%, mean outcome reward was 0.6719, the
selected post-update policy preserved validation reward 1.0, and peak reserved VRAM was 14.094 GiB.
The complete per-version reward history and the rejected terminal-policy result remain disclosed.

## Scope

This release validates mechanics on five tiny educational tasks and one validation task. It does
not claim general software-engineering performance, long-horizon Agent RL, a replay buffer,
accelerated rollout serving, or unrestricted tools. Those systems questions remain v0.4 work.
