# NanoPT v0.1.0 release notes

NanoPT v0.1.0 is the first complete alpha of the executable white-box post-training course.

## What is included

- A readable Qwen3 0.6B Base → LoRA SFT → DPO → synchronous GRPO/RLVR pipeline.
- Exact-token rollouts, deterministic synthetic arithmetic, strict verification, protected
  evaluation, regression reports, and independently resumable hash-linked artifacts.
- A secure five-task MiniSWE teaching environment with structured tools, isolated hidden
  verification, deterministic replay, and a hardened Docker reference backend.
- One prerequisite, 20 numbered chapters, 20 local labs, paper-reading guides, troubleshooting,
  systems simulations, a glossary, and contribution guides.
- Local and reference validation scripts with no GitHub Actions dependency.

## Measured reference result

On the pinned RTX 4070 Ti SUPER 16 GB profile, the fresh release run completed all 15 pipeline
stages in 221.9 seconds. Protected exact accuracy was 0.0% for Base, 86.4% for SFT, 84.1% for DPO,
and 88.6% for GRPO. Peak reserved memory was 7.41 GiB. The MiniSWE oracle solved 5/5 tasks and all
security probes passed.

## Important limits

- v0.1 evaluates agent policies but does not train them.
- Only the pinned reference GPU/profile has completed the full hardware protocol.
- Distributed runtimes, accelerated rollout servers, QLoRA, Agent SFT, and Agent RL are not part of
  the required path.
- Model weights, generated datasets, and adapters are not included in the release.
- PyPI publication and the public announcement remain deferred until the repository is public and
  the owner completes the credential and trademark decisions.

See the [M10 completion report](m10-completion-report.md) for commands, hashes, evidence, and the
release decision.
