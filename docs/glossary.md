# Glossary and notation index

This glossary uses NanoPT's exact meanings. When a paper uses a term differently, record the paper's
definition rather than silently substituting this one.

## A–D

- **Action:** a sampled decision. A language-model token ID is an action; MiniSWE additionally
  validates decoded text as one structured tool action.
- **Action mask:** boolean tensor selecting generated action-token positions and excluding prompt or
  padding positions.
- **Adapter:** trainable LoRA parameters applied to a frozen base model.
- **Advantage:** return or reward signal relative to a baseline; positive means the sampled action
  should become more likely under the policy-gradient convention.
- **Behavior/old policy:** policy distribution that generated retained actions and old log
  probabilities.
- **Checkpoint identity:** version/hash that binds model weights or an adapter to artifacts.
- **Clipping:** limiting the PPO-style objective's incentive outside a probability-ratio interval;
  not a hard policy-distance guarantee.
- **Completion mask:** action mask specialized to response tokens in a prompt/response sequence.
- **DPO:** Direct Preference Optimization using policy/reference chosen–rejected margins.

## E–L

- **Environment state:** complete transition state, including information not necessarily shown to
  the policy.
- **Exact sampled token IDs:** the categorical action identities returned by generation before
  decoding; never reconstructed by re-tokenizing text for training.
- **GRPO:** family of group-relative policy optimization methods; advantage, KL, clipping, and
  reduction variants must be named explicitly.
- **Hidden verifier:** trusted tests run outside the model-visible workspace with source/output
  withheld from observations.
- **KL divergence:** directed distribution difference. Exact categorical KL is nonnegative; one
  sampled direct log-ratio may be negative.
- **LoRA:** low-rank learned update added to a frozen weight matrix.
- **Log probability:** logarithm of a probability; token sequence log probability is normally a
  masked sum under NanoPT's DPO contract.

## M–R

- **Manifest:** versioned record binding config, code revision, data/checkpoint lineage, status, and
  artifacts.
- **Observation:** policy-visible view of environment state.
- **On-policy:** data generated by the policy distribution the update is meant to optimize, subject
  to the method's explicitly recorded old-policy contract.
- **Parse rate:** fraction of generated responses accepted by the strict response parser; separate
  from correctness.
- **Policy:** conditional action distribution being evaluated or optimized.
- **Policy version/staleness:** identifier/difference between rollout behavior weights and current
  weights when data completes or is consumed.
- **Protected split:** held-out data excluded from training, reward shaping, and recipe selection.
- **Reference policy:** frozen comparison policy in DPO or KL regularization; not the same as a
  reference hardware run.
- **Reference run:** complete pinned protocol executed on the claimed hardware tier.
- **Replay:** feeding retained actions through a fresh deterministic reset and comparing semantic
  transitions.
- **Reward:** scalar environment signal; may combine named components but is not automatically a
  return or advantage.
- **RLVR:** reinforcement learning with verifiable rewards.

## S–Z

- **Snapshot hash:** digest of an immutable task workspace used to prove deterministic reset.
- **SFT:** supervised fine-tuning; NanoPT masks prompts and optimizes completion tokens through LoRA.
- **Structured tool:** strict allow-listed JSON action whose arguments cross validated boundaries.
- **Trajectory:** ordered observations, actions, results, budgets, policy identity, termination, and
  final verification.
- **Termination:** environment-defined episode end such as policy finish or success.
- **Truncation/budget exhaustion:** external limit ends an episode without implying success.
- **Verifier:** trusted procedure mapping a candidate/task to correctness or another outcome.
- **White-box implementation:** project code exposes masks, objectives, order, and artifacts instead
  of delegating the lesson to a generic trainer.

## Symbol index

| Symbol | Meaning |
| --- | --- |
| $B$ | batch size |
| $T$ | sequence length |
| $V$ | vocabulary size |
| $G$ | completions per prompt group |
| $\pi_\theta$ | current policy |
| $\pi_{old}$ | behavior policy retained for a ratio |
| $\pi_{ref}$ | frozen reference policy |
| $r$, $R$, $A$ | reward, return, advantage |
| $\rho$ | current-to-old action probability ratio |
| $\epsilon$ | clipping or numerical-stability parameter, as locally defined |
| $\beta$ | DPO or KL coefficient, as locally defined |
